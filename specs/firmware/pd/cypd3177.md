# CYPD3177 USB-PD sink driver

The CYPD3177 is the board's USB-PD sink controller, whose power-delivery status
the firmware reads over I2C. `lib_CYPD3177` is the pure decode layer for that
status: the register map and the functions that turn a raw register word into an
engineering value. Each decoder is a pure transform on a single register word.

See also: [[usb-pd-monitoring]] (sys~pd_001~1), [[io/i2c]] (IO_i2c provides the
register transport for the CYPD3177 device layer).

## Register decode (lib_CYPD3177)

### Negotiated contract voltage
`fw~pd_001~1`

lib_CYPD3177 shall decode the negotiated contract voltage in millivolts from the
CURRENT_PDO register word as

$$V_{mV} = \text{PDO}[19{:}10] \times 50$$

where PDO[19:10] is the fixed-supply PDO voltage field.

Acceptance:
- A CURRENT_PDO word whose voltage field is 100 decodes to 5000 mV; a field of
  400 decodes to 20000 mV.

Covers:
- sys~pd_001~1

Needs: impl, test

### Negotiated contract current
`fw~pd_002~1`

lib_CYPD3177 shall decode the negotiated operating current in milliamps from the
CURRENT_RDO register word as

$$I_{mA} = \text{RDO}[19{:}10] \times 10$$

where RDO[19:10] is the RDO operating-current field.

Acceptance:
- A CURRENT_RDO word whose operating-current field is 150 decodes to 1500 mA; a
  field of 300 decodes to 3000 mA.

Covers:
- sys~pd_001~1

Needs: impl, test

### Explicit-contract state
`fw~pd_003~1`

lib_CYPD3177 shall decode whether an explicit PD contract is in place from bit 10
of the PD_STATUS register word.

Acceptance:
- A PD_STATUS word with bit 10 set decodes to an active contract; with bit 10
  clear it decodes to no active contract.

Covers:
- sys~pd_001~1

Needs: impl, test

### Bus voltage
`fw~pd_004~1`

lib_CYPD3177 shall decode the live bus voltage in millivolts from the
BUS_VOLTAGE register byte as

$$V_{mV} = \text{BUS\_VOLTAGE} \times 100$$

Acceptance:
- A BUS_VOLTAGE byte of 100 decodes to 10000 mV; a byte of 200 decodes to
  20000 mV.

Covers:
- sys~pd_001~1

Needs: impl, test

## Runtime status (dev_CYPD3177)

`dev_CYPD3177` is the runtime layer above the pure decoders. Channelized per
logical device, it fetches the CYPD3177 status registers through an `IO_i2c`
device channel, decodes them with the `CYPD3177_*` helpers, and caches the
result for firmware consumers. The decode arithmetic is owned by `fw~pd_001~1`
..`fw~pd_004~1` above and is not restated here.

### Device initialization and configuration validation
`fw~pd_005~1`

The dev_CYPD3177 driver shall validate the supplied configuration and initialize
every configured channel to the not-present state with zeroed status, returning
false if the configuration is rejected by any of:

| Element | Rejected when |
|---------|---------------|
| Config  | The config pointer or its channel array is NULL, or the channel count is not the compiled channel count. |
| Channel | Its IO_i2c device is out of range. |

Acceptance:
- A valid configuration initializes every channel to the not-present state with
  zeroed status and returns true.
- Each rejection condition returns false.

Covers:
- sys~pd_001~1

Needs: impl, test

### Status fetch
`fw~pd_006~1`

On a fetch of a channel, the dev_CYPD3177 driver shall read that channel's
device-mode, silicon-ID, PD-status, Type-C-status, bus-voltage, current-PDO, and
current-RDO registers through the channel's IO_i2c device, assemble each
register's bytes into a little-endian word, decode the words with lib_CYPD3177,
and update the channel's cached raw register words and decoded contract-active,
negotiated voltage, negotiated current, and bus voltage only when every register
read succeeds.

Acceptance:
- After a fetch whose reads decode to a known contract, the channel's cached
  contract-active flag and negotiated-voltage, negotiated-current, and
  bus-voltage values reflect that contract (decode values per `fw~pd_001~1`
  ..`fw~pd_004~1`).
- A four-byte register read of 0x00, 0x04, 0x00, 0x00 assembles to the word
  0x00000400.
- A fetch in which any register read fails leaves the channel's cached status
  unchanged.

Covers:
- sys~pd_001~1

Needs: impl, test

### Cached-status accessors
`fw~pd_007~1`

The dev_CYPD3177 driver shall return a channel's cached status through accessors
for contract-active, negotiated voltage in millivolts, negotiated current in
milliamps, and bus voltage in millivolts, and through a snapshot accessor that
copies the channel's complete cached state (raw register words plus decoded
values); a read of an out-of-range channel or of a channel before successful
initialization returns false or 0 (snapshot accessor: false, with the caller's
snapshot zeroed).

Acceptance:
- Each accessor returns the value stored by that channel's most recent successful
  fetch.
- The snapshot accessor returns the raw register words and decoded values stored
  by that channel's most recent successful fetch.
- A read of an out-of-range channel or before initialization returns false or 0
  (snapshot accessor: returns false and zeroes the caller's snapshot).

Covers:
- sys~pd_001~1

Needs: impl, test

### Device presence
`fw~pd_008~1`

The dev_CYPD3177 driver shall report a channel as present when its most recent
fetch read every register successfully and the device-mode register read back
nonzero.

Acceptance:
- After a fetch that reads every register with a nonzero device-mode, the channel
  reports present.
- A fetch whose device-mode reads back zero reports the channel not present.
- A fetch in which any register read fails reports the channel not present.

Covers:
- sys~pd_001~1

Needs: impl, test
